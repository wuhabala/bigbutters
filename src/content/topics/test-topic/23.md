#### 攀登题：绝对值矩阵的“黑客帝国”

已知 $x$ 是任意实数 ，请化简并求出以下含有分式与绝对值的复杂代数式 $M$ 的绝对最小值 ：

$$M = \frac{|x - 1| + [cite_start]|x + 5|}{2} + |x - 2|$$

> [!Success]- 答案与解析
>
> **【答案】** $M$ 的绝对最小值为 **4** 。
>
> **【解析】** 面对这种带有多个绝对值的代数式，如果盲目、机械地分段讨论，计算会极其冗长且容易出错 。我们需要学会摘下代数的面具，看清它在数轴上的空间几何动向 。
>
> 原式中有三个绝对值“零点”（即临界分界线）：$x = -5, x = 1, x = 2$ 。这三个点把整个一维数轴分割成了四个区间 。我们采用“区间拆分”与“整体边界”的组合拳来优雅解剖它 ：
>
> **第一步：解构前半部分的空间不变量** 我们先单独凝视前半部分：$A = \frac{|x - 1| + [cite_start]|x + 5|}{2}$ 。 在几何意义上，$|x - 1| + [cite_start]|x + 5|$ 代表数轴上的动点 $x$ 到两个固定点 $1$ 和 $-5$ 的距离之和 。这两个固定点之间的总距离为 $1 - (-5) = 6$ 。 * 根据“两点之间线段最短”，当动点 $x$ 刚好落在 $[-5, 1]$ 这个核心闭区间内部时，它到两点的距离之和恒定等于线段总长 $6$ 。此时，前半部分取得它一生中的恒定极小值：$A = \frac{6}{2} = 3$ 。 * 如果动点 $x$ 逃离了这个区间（例如 $x > 1$），那么前半部分就会开始随着 $x$ 的向右增大而线性长胖，去绝对值后变为 $\frac{(x - 1) + (x + 5)}{2} = x + 2$ 。
>
> **第二步：让两件空间拼图并网合流** 现在，我们让后半部分 $|x - 2|$ 加入战局，全面观察总和 $M$ 在数轴各区域的演化趋势 ： 1. **当 $x \le -5$ 时：** 动点跑到了最左边，所有绝对值内部全为负值，去掉符号变负后，代数式会向左剧烈上扬飙升（化简结果为 $M = -2x$），此处绝无最小值 。 2. **当 $-5 \le x \le 1$ 时：** 前半部分 $A$ 死死锁定在极小值 $3$ 。此时总式退化为：$M = 3 + |x - 2|$ 。在此区间内，由于 $x$ 最大只能摸到 $1$，所以 $x - 2$ 恒为负数，去掉绝对值符号变为 $2 - x$ 。因此 $M = 3 + (2 - x) = 5 - x$ 。当动点 $x$ 尽量往右靠、取到该区间的上限 $x = 1$ 时，$M$ 沉降到该区间的最低点：$M = 5 - 1 = 4$ 。 3. **当 $1 < x \le 2$ 时：** 奇迹发生了 ！在这个区间里，前半部分开始“解封”长胖，变为 $x + 2$ ；而后半部分 $|x - 2|$ 依然为负，去掉绝对值变为 $2 - x$ 。我们把两件动态的拼图加起来 ：
>
> $$M = (x + 2) + (2 - x) = 4$$
>
> 天呐！未知数 $x$ 竟然在相加的那一瞬间正负完美抵消，整体坍缩成了一个永恒的常数 ！在这个由 $1$ 到 $2$ 的平坦峡谷里，$M$ 恒等于 $4$ 。 4. **当 $x > 2$ 时：** 所有枷锁全部解封，两部分开始联合膨胀，化简变为 $M = (x + 2) + (x - 2) = 2x$ ，随着 $x$ 的增大而飙升 。
>
> **第三步：锁定谷底胜局** 综上所述，这个复杂的绝对值函数在数轴的连续演化中，在区间 $1 \le x \le 2$ 上沉降到了最平坦、最宁静的低谷，其绝对最小值为 **4** 。
>
> 🌟 **小数学家点评：** 看起来起伏波动的绝对值分式，通过区间的巧妙对消，在 $1$ 到 $2$ 之间留出了一片绝对静止的谷底 。控制边界的交集，就能完成大象无形的化简打击 ！

#### 冲顶题：钝角三角形的“周界硬锁定”

在 $\triangle ABC$ 中，已知两边长分别为 $a = 3$，$b = 5$ 。若已知这个三角形的第三条边 $c$ 对应的内角 $\angle C$ 是一个**钝角（大于 $90^\circ$）** 。

1. 请利用直角勾股定理的不等式衍化，求出第三边 $c$ 的代数取值范围 ；

2. 若 $c$ 的长度恰好是一个**整数** ，请问满足条件的三角形有几个？并求出这几个特殊三角形的周长 。


> [!Success]- 答案与解析
>
> **【答案】** > 1. $c$ 的代数取值范围为 $\sqrt{34} < c < 8$ ； 2. 满足条件的三角形有 **2** 个，它们的周长分别为 **14** 或 **15** 。
>
> **【解析】** 本题是极其经典的几何多重非线性不等式约束题 。第三边 $c$ 虽然处于连续的实数空间中，但它同时受到了大自然两道硬性枷锁的严格管控 。
>
> **第一步：祭出第一道枷锁——三角形生存基本法** 根据平面空间围合的第一铁律（两边之和大于第三边，两边之差小于第三边） ：
>
> $$5 - 3 < c < 5 + 3 \implies 2 < c < 8 \quad \text{(1)}$$
>
> 这一道基础的线性边界，率先将 $c$ 的活动范围锁定在了 $(2, 8)$ 的区间内 。
>
> **第二步：启动第二道枷锁——钝角空间的非线性形变** 在平坦的欧氏空间里，直角三角形的终极法则是由等号锁死的勾股定理 $a^2 + b^2 = c^2$ 。而如果夹角 $\angle C$ 撑得更开，变成了一个钝角（大于 $90^\circ$） ，那么它对面的大边 $c$ 的平方，必然会无情地打破等号，从而绝对压制住其余两边的平方和 。这就是勾股定理在非直角空间的不等式变形 ：
>
> $$c^2 > a^2 + b^2$$
>
> 我们将已知的双边参数 $a = 3, b = 5$ 强行整体塞入这道高阶约束中 ：
>
> $$c^2 > 3^2 + 5^2 = 9 + 25 = 34$$
>
> 由于边长 $c$ 必须是正数，两边同时开平方，不等号方向保持不变，成功阻击出关键的下边界 ：
>
> $$c > \sqrt{34} \quad \text{(2)}$$
>
> **第三步：双轨并网，精准剔除整数** 现在，我们将两道枷锁进行并网联立，求出第三边 $c$ 真正的生存峡谷 ：
>
> $$\sqrt{34} < c < 8$$
>
> 由于第二问给出了硬性限制—— $c$ 必须是**整数** ，我们需要调动关于“无理数估算”的直觉 。 我们知道：$5^2 = 25$，$6^2 = 36$ 。因为 $25 < 34 < 36$，所以 $\sqrt{34}$ 必定精准地坐落在 $5$ 到 $6$ 之间（大约为 $5.83$） 。 那么，在大于 $5.83$ 且小于 $8$ 的连续世界里，能够幸运存活下来的孤立**整数**，只能是 ：
>
> $$c = 6 \quad \text{或} \quad c = 7$$
>
> 这说明满足条件的特殊三角形刚好有 **2** 个！
>
> **第四步：收割周长战果** * 当第三边 $c = 6$ 时，三角形周长 $= 3 + 5 + 6 = 14$ ； * 当第三边 $c = 7$ 时，三角形周长 $= 3 + 5 + 7 = 15$ 。 至此，连续空间的无尽起伏被彻底定格为两个孤零零的数字。
>
> 🌟 **小数学家点评：** 直角是完美的等号，钝角则是拓宽的符号 。将勾股定理化作为边界的手术刀 ，就能在无序的实数连续体中，精准剔除并硬锁定出那两个孤立的整数灵魂 。这种用规则驯服连续性的体验，是数学底层结构最迷人的高光风景 ！
